# Security policy

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue or discussion.
Use this repository's **Security → Report a vulnerability** flow to send the
FlowCastle maintainers a private report.

Include the affected package and version or commit, impact, reproduction steps,
and any suggested mitigation. Do not include real customer bot tokens, SDK
keys, message content, or personal data. Use isolated test credentials and
redacted payloads.

We will acknowledge a complete report, investigate it privately, and coordinate
disclosure and remediation with the reporter. Supported releases and response
targets will be published here before the first stable package release.
